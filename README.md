# SoftBanto 紹介サイト

SoftBanto（そふと番頭、通称 番頭）を紹介する1枚の頁です。読む頁としても、番頭を説明するときのスライドとしても使えます。

ビルドはありません。`index.html`・`styles.css`・`site.js`・`assets/` だけで動きます。外のサービスからは何も読み込みません (字はパソコンに入っている書体を使います)。

## 「番頭を開く」ボタンの行き先

`site.js` の先頭の `BANTO_URL` に、番頭の画面 (Web アプリ) のリンクを入れます。

```js
const BANTO_URL = 'https://script.google.com/macros/s/xxxx/exec';
```

空のあいだは「番頭を開く」ボタンを出しません。

## プレゼンモード

| 操作 | 動き |
|---|---|
| 右上の「プレゼン」か `P` | 始める (いま見ている節から) |
| `→` `↓` `Space` `Enter`・画面のクリック | 次へ |
| `←` `↑`・画面の左端 4 分の 1 のクリック | 前へ |
| `Home` / `End` | 最初 / 最後 |
| `Esc` か `P` | 終えて、その節の位置に戻る |

各節が 1 枚ずつのスライドになります。全部で 12 枚 (はじめ・困りごと・できることの目次・できること 6 枚・使い始めるまで・よくある質問・締め)。
URL の末尾に `#slide-3` を付けて開くと、3 枚目から始まります。下の頁番号は「3 / 12」の形で出ます。

## 手元で見る

```bash
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## GitHub Pages に置く

1. このリポジトリを GitHub に送る
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` の `/ (root)` にする
3. 数分で `https://<アカウント>.github.io/<リポジトリ名>/` に出る

## 絵について

`assets/` の絵は、番頭に最初からいる推し (タク・イツキ) の絵を写したものです。
